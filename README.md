# ネタジェネレーター

「無関係を、ぶつけろ。」

流行データやAI APIを使わず、6カテゴリから独立してランダム抽選する静的Webアプリです。

## 特徴
- 外部APIなし
- OpenAI APIなどの従量課金なし
- 同一カテゴリでは全候補を一巡するまで同じ言葉を再使用しないシャッフルバッグ方式
- 6枠の中でも同じ言葉を重複させない
- 各項目を個別に固定／引き直し
- 固定していない項目だけ一括引き直し
- 抽選履歴はブラウザの `localStorage` に保存
- スマホ対応

## 使い方
`index.html` をブラウザで開くだけです。
GitHub Pagesでもそのまま公開できます。
